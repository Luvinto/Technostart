# 🚀 Technostart (Техностарт)

**Technostart** — это бесплатная веб-платформа для профориентации старшеклассников, разработанная на Python (Django). Проект создан с целью помочь школьникам сделать осознанный выбор профессии и предоставить им структурированные, качественные материалы для ознакомления с профессией.

> 💡 **Миссия:** Сделать качественную профориентацию и образовательные ресурсы доступными для каждого школьника, независимо от его местоположения и финансового положения.

---

## 🛠 Стек технологий

- **Backend:** Python 3.10+, Django
- **Database:** SQLite
- **Frontend:** HTML5, CSS3, JavaScript
- **Deployment:** Используется хостинг Beget


---

## ✨ Ключевые особенности и преимущества

1. **Полная бесплатность:** Все материалы платформы доступны без подписок и скрытых платежей.
2. **Фокус на самообучение:** Структурированные дорожные карты и статьи, адаптированные для самостоятельного изучения.
3. **Веб-доступность:** Не требует установки дополнительного ПО, работает на любых устройствах (ПК, планшеты, смартфоны).
4. **Понятный интерфейс:** Информация подается доступным языком, ориентированным на учащихся 9–11 классов, без излишнего академизма.
